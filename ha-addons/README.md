# Kwinten's Home Assistant Add-on Repository

[![Add to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fkwintenc%2Fha-addons)

## Add-ons

### 🖨️ Bambu Studio

Bambu Studio slicer running in your browser, embedded in the Home Assistant sidebar.

- Upstream image: [linuxserver/bambustudio](https://docs.linuxserver.io/images/docker-bambustudio/)
- Architecture: **amd64 only**
- Web UI via HA ingress (sidebar support)
- Dark mode & optional HTTP Basic Auth

---

## Installation

1. In Home Assistant go to **Settings → Add-ons → Add-on Store**.
2. Click the **⋮** menu (top right) → **Repositories**.
3. Add: `https://github.com/kwintenc/ha-addons`
4. Find **Bambu Studio** in the store and click **Install**.
